The problem

macOS stores Korean, Japanese and other composed characters in a decomposed form. The built-in Archive Utility copies that form into the ZIP as-is, so on Windows the letters fall apart. Going the other way, a ZIP made on Windows often carries filenames in a legacy code page, which Archive Utility only decodes correctly when it matches your Mac's system language.

What it does

  • Compressing: every filename is normalized to NFC and flagged as UTF-8, so it reads correctly on Windows, Linux and other Macs.
  • Extracting: archives made on Windows are inspected before extraction. jamoa guesses the legacy encoding (CP949, Shift_JIS, GB18030, Big5, CP1252 and more) and lets you switch it with a live preview of the filenames.
  • Formats: ZIP, TAR, TAR.GZ, TAR.XZ, TAR.BZ2 and 7Z for creating; those plus GZIP, XZ and BZIP2 for opening. ZIP archives can be encrypted with AES-256.
  • Finder integration: right-click to compress here or extract here.

Install

  1. Open the downloaded jamoa.dmg and drag jamoa into Applications.
  2. Launch it. The app is signed and notarized by Apple, so it opens without any workaround.
  3. Optional: turn on the Finder extension for right-click menus. See the first question below.

Questions

The right-click menu in Finder does not show jamoa

macOS turns off Finder extensions by default. Open System Settings › General › Login Items & Extensions › Finder Extensions and switch on jamoa.

Why does jamoa ask for permission to read a folder?

A Finder extension can tell jamoa which files you picked, but macOS does not let it hand over permission to read them. Allowing a folder once lets jamoa compress anything inside it without asking again. You can review or remove that permission in jamoa › Settings › File Access.

The name of my archive broke after I uploaded it somewhere

Names inside an archive are file content and survive any transfer. The name of the archive file itself is not, and some cloud services rewrite filenames during upload and download. This happens with any archiver. Using an English name for the archive file avoids it.

How do I get updates?

Choose jamoa › Check for Updates. jamoa never checks on its own.

Can jamoa open RAR files?

No. The licence for the RAR reference code does not permit it.

Privacy

jamoa collects nothing.

  • No personal data is collected, stored or transmitted.
  • No analytics, no tracking, no advertising identifiers.
  • Files you compress or extract never leave your Mac.
  • The only network request jamoa ever makes is when you choose Check for Updates: it reads the latest version number from GitHub. Nothing about you or your files is sent. The Mac App Store version has no such menu and makes no network requests at all.

어떤 문제인가

macOS는 한글을 자모가 분리된 형태로 저장합니다. 기본 압축 도구는 그 형태를 그대로 ZIP에 넣기 때문에 Windows에서 열면 글자가 풀어져 보입니다. 반대로 Windows에서 만든 ZIP은 파일명이 레거시 코드페이지로 들어 있는 경우가 많고, 기본 도구는 Mac의 시스템 언어와 맞는 코드페이지 하나만 제대로 풉니다.

기본 압축 도구 → Windows에서 열면 ㅂㅗㄱㅗㅅㅓ_ㅊㅚㅈㅗㅇ.docx
jamoa → Windows에서 열면 보고서_최종.docx

이 앱이 하는 일

  • 압축할 때: 모든 파일명을 NFC로 정규화하고 UTF-8 플래그를 세웁니다. Windows, Linux, 다른 Mac 어디서든 그대로 읽힙니다.
  • 풀 때: Windows에서 만든 압축 파일은 풀기 전에 미리 봅니다. 레거시 인코딩(CP949, Shift_JIS, GB18030, Big5, CP1252 등)을 추정하고, 인코딩을 바꾸면 파일명이 실시간으로 바뀌는 것을 보면서 고를 수 있습니다.
  • 형식: 만들기는 ZIP, TAR, TAR.GZ, TAR.XZ, TAR.BZ2, 7Z. 열기는 위 전부와 GZIP, XZ, BZIP2. ZIP은 AES-256 암호화를 지원합니다.
  • Finder 연동: 우클릭으로 여기에 압축, 여기에 풀기.

자주 묻는 것

Finder 우클릭 메뉴에 jamoa가 안 보입니다

macOS는 Finder 확장을 기본으로 꺼 둡니다. 시스템 설정 › 일반 › 로그인 항목 및 확장 프로그램 › Finder 확장 프로그램에서 jamoa를 켜주세요.

왜 폴더 접근 권한을 묻나요?

Finder 확장은 어떤 파일을 골랐는지 알려줄 수 있지만, macOS가 그 파일을 읽을 권한까지 넘기는 것은 허용하지 않습니다. 폴더를 한 번 허용하면 그 안의 항목은 다시 묻지 않고 압축합니다. 허용 내역은 jamoa › 설정 › 파일 접근에서 확인하고 해제할 수 있습니다.

어딘가에 올렸더니 압축 파일 이름이 깨졌습니다

압축 파일 안의 이름은 파일 내용이라 어떤 전송 경로에서도 안전합니다. 다만 압축 파일 자체의 이름은 다릅니다. 일부 클라우드 서비스가 올리고 내리는 과정에서 파일명을 다시 씁니다. 이건 어떤 압축 프로그램을 써도 같습니다. 압축 파일 이름만 영문으로 두면 피할 수 있습니다.

업데이트는 어떻게 받나요?

jamoa › 업데이트 확인을 누릅니다. jamoa가 스스로 확인하는 일은 없습니다.

RAR을 열 수 있나요?

열 수 없습니다. RAR 참조 코드의 라이선스가 이를 허용하지 않습니다.
