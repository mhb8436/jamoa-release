jamoa

Filenames intact on Windows

English한국어

What it does

jamoa is a file archiver for macOS. It normalizes filenames when compressing so they do not break apart on Windows, and it detects and corrects legacy encodings when opening archives made on Windows.

Formats: ZIP, TAR, TAR.GZ, TAR.XZ, TAR.BZ2 and 7Z for creating; those plus GZIP, XZ and BZIP2 for opening. ZIP archives can be encrypted with AES-256.

Questions

The right-click menu in Finder does not show jamoa

macOS turns off Finder extensions by default. Open System Settings › General › Login Items & Extensions › Finder Extensions and switch on jamoa.

Why does jamoa ask for permission to read a folder?

A Finder extension can tell jamoa which files you picked, but macOS does not let it hand over permission to read them. Allowing a folder once lets jamoa compress anything inside it without asking again. You can review or remove that permission in jamoa › Settings › File Access.

The name of my archive broke after I uploaded it somewhere

Names inside an archive are file content and survive any transfer. The name of the archive file itself is not, and some cloud services rewrite filenames during upload and download. This happens with any archiver. Using an English name for the archive file avoids it.

Can jamoa open RAR files?

No. The licence for the RAR reference code does not permit it.

Privacy

jamoa collects nothing.

  • No personal data is collected, stored or transmitted.
  • The app has no network entitlement and makes no network requests.
  • No analytics, no tracking, no advertising identifiers.
  • Files you compress or extract never leave your Mac.

이 앱이 하는 일

jamoa는 macOS용 압축 프로그램입니다. 압축할 때 파일명을 정규화해 Windows에서 자모가 분리되지 않게 하고, Windows에서 만든 압축 파일을 열 때는 레거시 인코딩을 추정해 깨진 이름을 복원합니다.

만들기: ZIP, TAR, TAR.GZ, TAR.XZ, TAR.BZ2, 7Z. 열기: 위 전부와 GZIP, XZ, BZIP2. ZIP은 AES-256 암호화를 지원합니다.

자주 묻는 것

Finder 우클릭 메뉴에 jamoa가 안 보입니다

macOS는 Finder 확장을 기본으로 꺼 둡니다. 시스템 설정 › 일반 › 로그인 항목 및 확장 프로그램 › Finder 확장 프로그램에서 jamoa를 켜주세요.

왜 폴더 접근 권한을 묻나요?

Finder 확장은 어떤 파일을 골랐는지 알려줄 수 있지만, macOS가 그 파일을 읽을 권한까지 넘기는 것은 허용하지 않습니다. 폴더를 한 번 허용하면 그 안의 항목은 다시 묻지 않고 압축합니다. 허용 내역은 jamoa › 설정 › 파일 접근에서 확인하고 해제할 수 있습니다.

어딘가에 올렸더니 압축 파일 이름이 깨졌습니다

압축 파일 안의 이름은 파일 내용이라 어떤 전송 경로에서도 안전합니다. 다만 압축 파일 자체의 이름은 다릅니다. 일부 클라우드 서비스가 올리고 내리는 과정에서 파일명을 다시 씁니다. 이건 어떤 압축 프로그램을 써도 같습니다. 압축 파일 이름만 영문으로 두면 피할 수 있습니다.

RAR을 열 수 있나요?

열 수 없습니다. RAR 참조 코드의 라이선스가 이를 허용하지 않습니다.
